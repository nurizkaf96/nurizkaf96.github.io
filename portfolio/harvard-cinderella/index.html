Project's Overview

Harvard Cinderella is an English-language course provider based in Bandung. The project introduced two applications for its two primary user groups: teachers and students.

The Teacher App helps teachers manage class schedules, record and review students, and access new classes to teach. The Student App serves both existing and prospective students, allowing them to discover and purchase courses offered by Harvard Cinderella.

Project's Challenge

How might we distribute class informations for teachers and students so that the learning process proceed accordingly and properly

Project's Process

The application development process started with a requirements analysis with the client. Those requirements were then translated into features and milestone targets for developers and designers. Each milestone was presented to the client for confirmation, with room for iteration when issues were identified at that stage.

This established a structured cycle:

  1. Analyze requirements with the client.
  2. Translate requirements into features and milestone targets.
  3. Design and develop against each milestone.
  4. Review with the client at each milestone.
  5. Iterate when errors or changes were identified.

Additional Story

This was the first full-scale project I handled as a project manager. The project was also handed over under non-ideal circumstances: initially, I was assigned only as the UI/UX Designer because another person was the project manager. I later took on the project management responsibility.

One of the main challenges was internal team coordination. The project manager role placed me in a position that was younger and more junior than members of the development team. This created situations where disagreements occurred, requiring me to learn how to position myself more effectively within the team and establish the role's authority.

Learning & Takeaways

The project became an important transition from primarily working as a UI/UX Designer into managing a larger project and development team. Its less-than-ideal starting conditions created an opportunity to move beyond an existing comfort zone and develop practical project leadership skills.
