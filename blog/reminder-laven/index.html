Figma Reminders: Layers, Layout & Properties

Personal Figma reminders: check layers and names, watch FILL / HUG / FIX sizing, and read the property labels before entering values.

  1. Lihat layer, selalu check posisi layer
  2. Namain layernya!!
  3. Perhatikan width atau heightnya. Apakah FILL, HUG, FIX?
  4. Perhatikan auto layout setting. Jangan salah masukin angka.
  5. Baca label sebelum input angka di panel properties (autolayout, fill, stroke, dkk)
